# J-Space and ESMC SAE Replications: Investigating a Protein Global Workspace

This document compiles literature, web research, and a mechanistic critique of J-spaces and the ESMC (Evolutionary Scale Modeling Cambrian) Sparse Autoencoder (SAE) results. It translates the "Global Workspace" paradigm to protein biology, resolves critical architectural differences, and designs a concrete **falsification test suite** with an interactive **marimo notebook** implementation to execute the investigation.

---

## 1. Literature & Web Research Synthesis

### J-Spaces and the Jacobian Lens (Anthropic, July 2026)
Gurnee, Sofroniew, Lindsey et al. introduced the concept of **J-space** in *"Verbalizable Representations Form a Global Workspace in Language Models"*.
*   **Mechanism**: The **Jacobian Lens (J-lens)** computes the gradient matrix $\mathbf{J}_{\ell} = \mathbb{E}[\partial h_{\text{final}} / \partial h_{\ell}]$ of final-layer output logits (or hidden representations) with respect to intermediate activations $h_{\ell}$.
*   **J-space**: Defined as a sparse, non-negative combination of these J-lens vectors.
*   **Hypothesis**: J-space acts as a functional analog of the human brain's **Global Workspace Theory (GWT)**—a centralized, low-variance routing hub where concepts are brought into a shared space for manipulation, broadcast to multiple downstream tasks, and verbalized.
*   **Causal Claims**: Ablating or patching the J-space causally steers downstream behavior across otherwise unrelated prompts.

#### Independent Replications of J-Spaces
Independent researchers replicated the J-space phenomenon on **Qwen 3.6 27B** (an open-weights model). They discovered:
*   **Interpretative Meta-Tokens**: When English text contains semantic ambiguity, the model's residual stream projects strongly onto specific multilingual tokens (such as Chinese characters representing "meaning" or "resolution").
*   **Causal Steerability**: Modulating or pinning these directions in Qwen's middle layers alters the model's resolution of downstream semantic ambiguity.
*   **Caveat**: The model isn't "thinking in Chinese." Rather, the J-lens acts as an unembedding translator, mapping a high-dimensional, abstract uncertainty-resolving circuit to the closest, most semantically dense token in its vocabulary.

### ESMC and Sparse Autoencoders (Biohub/EvolutionaryScale, Jan-Jun 2026)
The ESMC Cambrian model family represents a world model of protein biology. In the ESMC paper, **Figure 4** displays an unsupervised **SAE feature atlas** (layer 60 of the 6B model, swept dictionary sizes $2^{13}$ to $2^{17}$, and $K=8$ to $128$ active features per residue).
*   The atlas maps features along two axes: **Specificity** (universal to family-specific) and **Granularity** (residue-level to domain-level).
*   The features capture a hierarchy of physical and functional abstractions: physical scale (charge, hydrophobicity), secondary structural motifs (alpha/beta propensities), and high-level functional concepts (catalytic sites, active pockets).

#### Independent Replications of ESMC SAE
In mid-2026, **YueHuLab** published:
*   **Title**: *"Interpretable enzyme function prediction via sparse autoencoder features of ESMC across the microbial protein universe"* (arXiv:2606.12209).
*   **Core Replication**: They used the 16,384 features from the ESMC-6B layer-60 SAE (annotated by GPT-5) as "semantic signatures" without fine-tuning.
*   **Results**:
    *   Achieved **78.9% top-1** and **88.5% top-5 accuracy** in predicting Enzyme Commission (EC) numbers on a SwissProt benchmark of 4,868 microbial enzymes, dramatically outperforming sequence-based baselines.
    *   Substantiated that these features capture high-level biology (catalytic triads in hydrolases, NAD(P)H-binding Rossmann folds in oxidoreductases) and generalize to novel enzyme classes.

## 2. Redefining J-Spaces for Protein Language Models

Transplanting J-space onto a protein language model (pLM) like ESMC requires overcoming three key mathematical and architectural mismatches:

### A. The Vocabulary Problem (Low Token Resolution)
In text models, the vocabulary has $\sim 100\text{k}$ tokens, allowing a high-dimensional projection of abstract concepts. In pLMs, the "vocabulary" is only 20 standard amino acids (plus special tokens like BOS/EOS/MASK).
*   **Literal J-lens**: Computing the Jacobian with respect to the 20 amino acid output logits yields only a 20-dimensional space, far too small to represent a structured global workspace.
*   **Protein Redefinition**: Rather than sequence logits alone, the Jacobian must target downstream **multi-task readouts** ($R$):
    1.  **Masked Sequence Logits**: The probability distribution over the 20 amino acids across all sequence positions (yielding $L \times 20$ dimensions).
    2.  **Structural Coordinate Heads**: The 3D coordinates or frame representations generated by the model's folding module (e.g., Invariant Point Attention).
    3.  **Supervised Probes**: Linear probes trained to classify biological properties (EC subclasses, GO terms, subcellular localization).
    
    Mathematically, for a task readout $R(h)$, the protein J-lens vector is defined as:
    $$\mathbf{J}_{R, \ell} = \mathbb{E}\left[ \frac{\partial R(h_{\text{final}})}{\partial \mathbf{h}_{\ell}} \right]$$

### B. Autoregressive Causal vs. Masked Bidirectional
Text models predict the "next token" causally, mapping "what the model is about to say." ESMC is a masked language model (MLM). It predicts masked residues using context from both directions.
*   **Workspace Translation**: In a pLM, the workspace does not manage causal, temporal broadcasting of text generation. Instead, it must manage **global biophysical constraints** (such as folding topology, domain-domain interactions, and biochemical microenvironments) and broadcast them bidirectionally to local residue positions.

### C. The Skeptical Critique: Workspace vs. Unembedding Artifact
Is J-space an authentic biological workspace, or a circular artifact of backpropagation?
*   **Workspace (Generalized Broadcast)**: A small, layer-localized bottleneck that holds abstract biophysical concepts and is read by *multiple, independent downstream circuits*. Modulating it causes coordinated shifts across all tasks.
*   **Unembedding Bias (Modular Routing)**: The J-lens is forced to find directions that map linearly to the output. If the model is modular, perturbing a direction will affect only one specific task (e.g. EC number) while leaving other independent tasks (e.g. structural coordinates) completely untouched.

## 3. Causal Falsification Protocol

To empirically determine if ESMC SAE features act as a true global workspace or simply modular pipelines, we define a causal intervention sweep on the residual stream at layer $\ell$.

### 1. Extracting the Candidate Vector ($\mathbf{v}$)
Let $\mathbf{v} \in \mathbb{R}^d$ be the direction of interest (e.g., an active site feature like Serine Hydrolase nucleophile elbow `F6716` from the ESMC-6B layer-60 SAE).

### 2. Defining Interventions
For a hidden state $\mathbf{h}_{\ell}$ at layer $\ell$, we define three interventions:
1.  **Targeted steering**: Perturb specifically along the feature direction $\mathbf{v}$:
    $$\mathbf{h}_{\ell}' = \mathbf{h}_{\ell} + \alpha \frac{\mathbf{v}}{\|\mathbf{v}\|}$$
2.  **Isotropic noise control**: Perturb along a random unit vector $\mathbf{r} \sim \mathcal{N}(0, \mathbf{I})$:
    $$\mathbf{h}_{\ell}^* = \mathbf{h}_{\ell} + \alpha \mathbf{r}$$
3.  **Orthogonal complement scramble**: Leave the feature direction $\mathbf{v}$ intact while scrambling all other orthogonal dimensions:
    $$\mathbf{h}_{\ell}^{\perp} = \mathbf{v}(\mathbf{v}^T \mathbf{h}_{\ell}) + (\mathbf{I} - \mathbf{v}\mathbf{v}^T)(\mathbf{h}_{\ell} + \alpha \mathbf{r})$$

### 3. Falsification Criteria
We track how performance degrades on multiple downstream tasks (Sequence MLM loss, Structure Prediction loss, EC class, Subcellular Localization) as a function of perturbation magnitude $\alpha$:

*   **Verdict: Workspace Theory Supported**:
    *   Steering along $\mathbf{v}$ degrades *multiple* unrelated tasks simultaneously (showing a shared broadcast bottleneck).
    *   Scrambling the complement preserves performance on the core task associated with $\mathbf{v}$ (showing that the workspace holds the concept compactly).
*   **Verdict: Modular/Circularity Theory Supported (Workspace Falsified)**:
    *   Steering along $\mathbf{v}$ degrades *only* its target task, while other tasks remain completely unaffected.
    *   Scrambling the complement degrades the target task as much as random scrambling, suggesting the concept is distributed and not isolated to $\mathbf{v}$.

app = marimo.App(width="medium")


@app.cell
def _():

    import plotly.graph_objects as go

@app.cell(hide_code=True)
def _(mo):
    mo.md(
        r"""
        # 🧬 Protein J-Space & Jacobian Falsification Suite

        This notebook investigates whether protein representation spaces contain a **Global Workspace (J-space)**
        or behave as a **modular/distributed feedforward network**.

        We register PyTorch hooks to intercept the residual stream of `biohub/esmc-300m-2024-12` and perform:
        1. **Targeted Steering**: perturbing along a candidate feature direction $\mathbf{v}$ (derived from SAE or probe).
        2. **Isotropic Noise Control**: perturbing along a random direction $\mathbf{r}$.
        3. **Orthogonal Complement Scrambling**: scrambling the orthogonal complement $\mathbf{P}_{\perp}\mathbf{h}$ while preserving $\mathbf{v}$."""
    )
    return

@app.cell
def load_model(AutoModelForMaskedLM, AutoTokenizer, model_dropdown):
    model_id = model_dropdown.value
    # Load the base model and tokenizer
    tokenizer = AutoTokenizer.from_pretrained(model_id, trust_remote_code=True)
    model = AutoModelForMaskedLM.from_pretrained(model_id, trust_remote_code=True).eval()
    return model, tokenizer


@app.cell
def run_falsification(
    alpha_slider,
    layer_slider,
    model,
    sequence_input,
    tokenizer,
    torch,
):
    seq = sequence_input.value
    layer_idx = layer_slider.value
    alpha = alpha_slider.value
    
    # Encode inputs
    inputs = tokenizer([seq], return_tensors="pt")
    
    # 1. Forward pass to get original hidden states and build candidate direction (v)
    with torch.no_grad():
        outputs = model(**inputs, output_hidden_states=True)
        hidden_states = outputs.hidden_states
    
    # Let's derive a candidate vector v.
    # In this demonstration, we use the first principal component of the layer's hidden states
    # representing a major structural backbone concept.
    h_l = hidden_states[layer_idx][0]  # (SeqLen, HiddenDim)
    h_l_mean = h_l.mean(dim=0, keepdim=True)
    h_l_centered = h_l - h_l_mean
    _, _, V = torch.pca_lowrank(h_l_centered, q=1)
    v = V[:, 0]  # Candidate J-space direction (HiddenDim,)
    v = v / torch.norm(v)

    # 2. Define the Hook class for intervention
    class InterceptionHook:
        def __init__(self, layer, direction, alpha, mode):
            self.layer = layer
            self.v = direction
            self.alpha = alpha
            self.mode = mode
            
        def __call__(self, module, inputs, outputs):
            # Intercept the residual state
            h = outputs[0] if isinstance(outputs, tuple) else outputs
            
            if self.mode == "steer":
                # Steering along candidate vector v
                intervention = self.alpha * self.v.view(1, 1, -1)
                h_new = h + intervention
            elif self.mode == "random":
                # Random isotropic noise matching magnitude
                r = torch.randn_like(h)
                r = r / torch.norm(r, dim=-1, keepdim=True)
                h_new = h + self.alpha * r
            elif self.mode == "scramble_complement":
                # Project out v, scramble the rest
                v_unsqueezed = self.v.view(1, 1, -1)
                projected = torch.sum(h * v_unsqueezed, dim=-1, keepdim=True) * v_unsqueezed
                complement = h - projected
                r = torch.randn_like(complement)
                r_ortho = r - torch.sum(r * v_unsqueezed, dim=-1, keepdim=True) * v_unsqueezed
                r_ortho = r_ortho / torch.norm(r_ortho, dim=-1, keepdim=True)
                h_new = projected + (complement + self.alpha * r_ortho)
            else:
                h_new = h
                
            if isinstance(outputs, tuple):
                return (h_new,) + outputs[1:]
            return h_new

    # Helper function to run model with a registered hook
    def evaluate_hook(mode):
        # We hook the specific transformer layer
        target_layer = model.esm.encoder.layer[layer_idx]
        hook_obj = InterceptionHook(layer_idx, v, alpha, mode)
        handle = target_layer.register_forward_hook(hook_obj)
        
        with torch.no_grad():
            outputs = model(**inputs)
            # Evaluate sequence logits cross entropy
            logits = outputs.logits  # (1, SeqLen, AlphabetSize)
        handle.remove()
        return logits

    # Run sweeps
    orig_logits = evaluate_hook("none")
    steer_logits = evaluate_hook("steer")
    rand_logits = evaluate_hook("random")
    scramble_logits = evaluate_hook("scramble_complement")
    
    # Calculate Kullback-Leibler (KL) divergence from original predictions to evaluate degradation
    def compute_kl(pred_logits, target_logits):
        p = torch.nn.functional.softmax(target_logits, dim=-1)
        log_p = torch.nn.functional.log_softmax(target_logits, dim=-1)
        log_q = torch.nn.functional.log_softmax(pred_logits, dim=-1)
        kl = torch.sum(p * (log_p - log_q), dim=-1).mean().item()
        return kl

    kl_steer = compute_kl(steer_logits, orig_logits)
    kl_rand = compute_kl(rand_logits, orig_logits)
    kl_scramble = compute_kl(scramble_logits, orig_logits)
    
    return kl_rand, kl_scramble, kl_steer


@app.cell
def plot_results(go, kl_rand, kl_scramble, kl_steer, mo):
    categories = ["Targeted Steering", "Random Isotropic Noise", "Orthogonal Scrambling"]
    values = [kl_steer, kl_rand, kl_scramble]
    
    fig = go.Figure(data=[
        go.Bar(
            x=categories,
            y=values,
            marker_color=["#dd8452", "#bcbcbc", "#4c72b0"],
        )
    ])
    fig.update_layout(
        title="Task Representation Degradation (KL Divergence from Baseline)",
        xaxis_title="Intervention Mode",
        yaxis_title="Degradation (higher = more disruption)",
        template="plotly_dark",
        paper_bgcolor="#111111",
        plot_bgcolor="#111111",
    )
    
    chart = mo.as_html(fig)
    chart
    return categories, chart, fig, values


@app.cell
def interpretation(kl_rand, kl_scramble, kl_steer, mo):
    if kl_steer > kl_rand * 1.5:
        verdict = mo.md(
            r"""> 🔬 **Verdict**: **Modular Routing Hypothesis Supported**.  
> Steering along the candidate vector causes significantly *greater* degradation than random noise, indicating that this direction represents a highly specific, modular routing pathway rather than a shared, resilient global workspace."""
        )
    elif kl_scramble < kl_rand * 0.7:
        verdict = mo.md(
            r"""> 🧠 **Verdict**: **Global Workspace Hypothesis Supported**.  
> Scrambling the orthogonal complement causes significantly *less* degradation than random noise, suggesting that the candidate vector successfully isolates the load-bearing information, and the rest of the subspace contains redundant, high-entropy representation."""
        )
    else:
        verdict = mo.md(
            r"""> ⚖️ **Verdict**: **Inconclusive**.  
> The degradation profiles are comparable across controls, indicating that further multi-task evaluation is required to segment functional routing."""
        )
    
    mo.vstack([
        mo.md("### Automated Hypothesis Judgment"),
        verdict
    ])
    return (verdict,)


if __name__ == "__main__":
    app.run()
